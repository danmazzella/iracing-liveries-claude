# iRacing paint templates

Put the car templates (`.psd`) here, named as iRacing ships them, e.g. `BMW M4 GT3.psd`.
They aren't in the repo: download each car's template from iRacing (the car's page on
iracing.com, "paint template"), unzip it and drop the `.psd` in this folder.

Scripts find them by file name: `cars/<car>/README.md` has a `Template: \`<file>.psd\`` line,
and each livery names its template in its car config.
