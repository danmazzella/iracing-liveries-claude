# logos

Put your own logos here (PNG or WebP with a transparent background, as big as you have).
Only this README is shared on GitHub: logo files in this folder stay on your computer.

Tips:
- Transparent background, cropped tight. Big source files: logos get scaled to fit their spot.
- Single-colour line art disappears on the same colour behind it. Give it an outline or
  a contrasting panel.
- Don't stretch lettering to fill a space; it reads wrong on the car.
